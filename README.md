MathMaster'Pro.AI
MathMaster'Pro.AI is a 100-level adaptive web-based math tutor and skill tracker designed to help learners master fundamental arithmetic operations through 100 progressive difficulty levels, interactive micro-lessons, and personalized session logs.
---
🚀 Features
Adaptive Skill Levels: 100 progressive levels spanning Addition, Subtraction, Multiplication, and Division.
Student Authentication & Session Tracking: Secure local registration/login via username and PIN code, complete with session timestamps and recent activity history logs.
Dynamic Study Guides: Built-in step-by-step visual working guides that trigger automatically after consecutive incorrect attempts.
Interactive Feedback & Celebration: Real-time evaluation, celebration banners, and celebratory animations upon completing problem streaks.
Zero-Dependency Architecture: Built entirely with vanilla HTML5, modern CSS3, and ES6 JavaScript, leveraging `localStorage` for persistent offline-first student progress tracking.
---
🛠️ Tech Stack
Frontend: HTML5, CSS3 (Custom Properties & Responsive Grids)
Scripting: Vanilla JavaScript (ES6+ Classes, DOM Manipulation)
Storage: Browser `localStorage` API
